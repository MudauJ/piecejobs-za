Add multi-task booking system to PieceJobs ZA with two booking types.

## DATABASE CHANGES
Run this SQL in Supabase:

ALTER TABLE jobs ADD COLUMN IF NOT EXISTS categories TEXT[] DEFAULT '{}';
ALTER TABLE jobs ADD COLUMN IF NOT EXISTS booking_type TEXT DEFAULT 'single';
ALTER TABLE jobs ADD COLUMN IF NOT EXISTS parent_job_id UUID REFERENCES jobs(id);

CREATE TABLE IF NOT EXISTS job_tasks (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  parent_job_id UUID REFERENCES jobs(id) ON DELETE CASCADE,
  category TEXT NOT NULL,
  description TEXT,
  estimated_budget INTEGER,
  assigned_worker_id UUID REFERENCES workers(id),
  status TEXT DEFAULT 'open',
  created_at TIMESTAMPTZ DEFAULT NOW()
);

ALTER TABLE job_tasks DISABLE ROW LEVEL SECURITY;
GRANT ALL ON job_tasks TO anon, authenticated;

## COMPATIBLE TASK GROUPS
Define which tasks can be done by one worker (bundle) vs need separate workers:

BUNDLE COMPATIBLE (one worker can do all):
Group 1 — Domestic: Cleaning, Laundry, Dishwashing, Ironing
Group 2 — Outdoor: Garden, Grass cutting, Pool Cleaning
Group 3 — Skilled: Painting, Tiling & Grouting
Group 4 — Care: Dog Walking, Childcare
Group 5 — Other: Braai Setup, Car Wash, Cooking, Tutoring

NEEDS SEPARATE WORKERS (incompatible with other groups):
- Plumbing (always separate)
- Electrical (minor) (always separate)
- Moving & Lifting (always separate)
- Any mix across the 5 groups above needs separate workers

## JOB CREATION LOGIC

If BUNDLE booking:
- Create ONE job record with:
  - categories = array of all selected categories
  - booking_type = 'bundle'
  - title = auto-generated e.g. "Cleaning, Laundry & Grass cutting"
  - budget = combined budget

If MULTI-WORKER booking:
- Create MULTIPLE job records, one per incompatible group:
  - Each job has booking_type = 'multi'
  - Each job has parent_job_id linking them together
  - Each job has its own category, description, budget
- Show homeowner: "3 jobs created for your booking"
